# 4. Hafta – QA Test Specialist

## Çalışmanın Amacı

NovaMarket satış raporunun belirlenen iş gereksinimleri ve iş kurallarıyla uyumunu kontrol ederek raporun **doğruluğunu, güvenilirliğini ve yayına hazır olma durumunu** değerlendirmek.

## Gerçekleştirilen Çalışmalar

* İş gereksinimlerinin ve kabul kriterlerinin incelenmesi
* Test sürecine yönelik mini test planının oluşturulması
* Pozitif, negatif ve sınır değer senaryolarının hazırlanması
* Test case'lerin oluşturulması
* Belirlenen senaryoların veri seti üzerinde uygulanması
* Beklenen ve gerçekleşen sonuçların karşılaştırılması
* Tespit edilen hataların dokümante edilmesi ve bug raporlarının hazırlanması
* Hataların severity ve priority seviyelerine göre değerlendirilmesi
* Test sonuçlarına göre **GO / Conditional GO / NO-GO** kararının verilmesi

## Kazanılan Yetkinlikler

* Manual Testing
* Requirement & Acceptance Criteria Analizi
* Test Case Tasarımı
* Pozitif, Negatif ve Boundary Testing
* Bug Raporlama
* Severity & Priority Değerlendirmesi
* Test Sonuçlarının Analizi
* QA Raporlama
* Release Readiness Değerlendirmesi
